# Employee Attrition Analysis Dashboard

## Project Overview
This Power BI dashboard analyzes employee attrition trends and workforce metrics to help organizations understand employee turnover patterns.

## Tools Used
- Power BI
- MS Excel
- SQL
- Data Analysis

## Key KPIs
- Total Employees
- Attrition Count
- Average Rate
- Gender count
- Average Monthly Income

## Dashboard Insights
- Executive Summary
- Attrition Analysis
- Salary and Job role Analysis
- Employee satisfaction and wellness
- Workforce Demographics

## Files Included
- Attrition analysis dashboard.pbix

## Project Objective
To identify factors contributing to employee attrition and provide insights that support employee retention strategies.
